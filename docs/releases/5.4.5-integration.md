- Combine both sets of localization keys. Preserve credential storage and database migrations; do not reset user data.
- Use official Home memoization and keyset mix paging with the fork's logical source boundaries. Preserve offline-copy origins and collection namespaces.
- Preserve paused transport intent through retries, format fallback and Cast handoff. Retire obsolete source work before it can publish a new item.
- Use the same saved-source switches in Settings and Library. Normalize root URLs with and without a trailing slash; disabled servers remain manageable.
- Apply existing cache enable, Wi-Fi and size preferences to official prefetch. Avoid prefetching an already verified cached/offline song.

## Radio

Native AVPlayer timed metadata snapshots support HLS/ID3. A cancellable ICY reader requests real broadcast metadata with bounded bytes/time and at most one inspection per 15 seconds. Old station callbacks cannot update a new selection. The station ID and source remain stable; actual artist/title/album replace only display metadata. Empty metadata restores the station fallback. No fake station catalog is generated.

Artwork lookup reuses the existing strict catalog matcher/cache. Lyrics reuse the configured provider, clear immediately per real track identity, reject late results and never write to a broadcast URL. Timed lyrics remain available as text because the broadcast does not supply a reliable song offset. LIVE controls stay centered at 320, 768 and 1280 pixels.

## Equalizer investigation

The existing engine remains audioplayers with the vendored Darwin PCM tap, and Android session effects. EQ settings and bands remain intact. Darwin attachment now checks the item/revision before installing its mix and preserves the current Play/Pause intent after renderer rebuilding. This closes an asynchronous lifecycle gap. It is **not yet proof of the reported Bluetooth-device failure's root cause**. Native compilation/playback, real iPhone and Bluetooth acceptance remain pending. EQ is not disabled for Bluetooth.
