# Direct library playback: cold NAS/cache recovery

The physical iOS 27.2 / Sony WH-1000XM6 test confirmed the concrete-track FLAC EQ fix. This change leaves the native EQ path unchanged.

## Reproduced defects

A foreground Subsonic proxy request awaited the background cache producer's headers without a bound. Once headers existed, reading the partial spool could still wait indefinitely for more cached bytes. Both gated-producer regressions failed with a two-second deadline before the fix, despite a healthy authenticated origin. A second fallback rejected HTTP 200 from origins that ignore Range.

Library selections also awaited file resolution and player initialization before the handler's generation guard existed. An older selection could therefore replace a newer queue. Selection generations now start before those awaits and are invalidated by Next, Previous and queue jumps. The handler's serialized source changes remain in place.

## Behavior

- Unknown cache length immediately uses progressive origin streaming.
- A healthy progressing spool is reused. A stalled spool hands off at its exact byte offset after a short 240 ms no-progress budget; background caching continues.
- Origins returning a full HTTP 200 response to Range are sliced to the requested byte window without duplicating the already emitted prefix.
- Partial files remain hidden from completed-cache lookup; verified publication remains unchanged.
- Old position callbacks cannot start prefetch while the newly selected source is still loading.
- No longer playback delay, cache disable, native player reset, EQ changes, library migration or UI redesign.

## Validation checkpoint

110 targeted Flutter tests passed, including stalled cache with/without known length, a distant seek against a Range-ignoring origin, progressing partial reads, 5/10/20 reversed-order library resolutions, Next during source resolution, existing playlist ordering, cache and recovery suites. Targeted analysis: no errors or warnings, three existing informational lints. Native integration now also holds a FLAC cache fill incomplete while AVPlayer streams with EQ off and then verifies actual -6 dB EQ processing. The new native run and physical Bluetooth retest are pending at this checkpoint.

The separate HLS-radio PCM/EQ issue remains open; this change does not claim to resolve it.

## Additional reproduced route eviction

A prepared playback URL returned HTTP 404 after 300 background library resolutions: the shared 256-entry opaque route table evicted the active stream alongside disposable browsing routes. The bounded eviction policy now removes browsing routes first, protecting recent playback routes without expanding the table or exposing names/credentials. The new regression fails with 404 before this change and receives the correct progressive 206 bytes afterward.
